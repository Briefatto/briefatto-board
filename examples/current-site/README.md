# Sedge Ferry

A two-page static site for a fictional ferry service. Open [Crossing times](index.html) and [Before you sail](about.html) to see the same masthead, crossing panel and rules applied to a timetable and a boarding guide. Both pages use [the shared stylesheet](ferry.css).

Copy this example to a working folder and install Briefatto Board there. Capture both pages and review the screenshots and computed styles.

```sh
node .claude/skills/briefatto-board/board.mjs adopt .
```

To reproduce the recorded version, copy [the example guide](recorded/DESIGN.md) to `DESIGN.md` in the working folder. Freeze the guide and view its version.

```sh
node .claude/skills/briefatto-board/board.mjs freeze .
node .claude/skills/briefatto-board/board.mjs log
```
